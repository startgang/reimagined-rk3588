# Правило: описание добавленных компонентов в `hw/bom/README.md`

Каждый раз, когда в папку `hw/bom/` добавляется новый PDF (или каталог компонентов),
обновить `hw/bom/README.md` — таблицу компонентов несущей платы.

## Формат таблицы

Три столбца: `№` | `Название папки` | `Компонент`.

- `№` — порядковый номер строки (1, 2, 3, …).
- `Название папки` — markdown-ссылка на папку относительно `hw/bom/`,
  например `[connectors/comexpress](connectors/comexpress)`.
- `Компонент`:
  - если в папке **один компонент** (один PDF) — имя компонента со ссылкой
    на этот PDF, например
    `[3-1827253-6 (разъём COM Express Type 6, Molex)](connectors/comexpress/3-1827253-6.pdf)`;
  - если в папке **каталог компонентов** (несколько PDF) — общее название
    каталога со ссылкой на саму папку.
  - Если у компонента есть понятное название из PDF (маркировка, тип,
    производитель) — добавить его в скобках после имени файла.

## Правила

1. Таблица — единственный контент после заголовка `# Компоненты для несущей платы`,
   без лишнего текста.
2. Ссылки — относительные, от `hw/bom/README.md`.
3. При добавлении компонента:
   - дописать новую строку в конец таблицы;
   - перенумеровать строки заново, если порядок меняется.
4. Не удалять и не переписывать уже существующие строки без необходимости.
5. После обновления файла — закоммитить с сообщением вида
   `docs: add <component> to BOM` (типы по git-правилу репозитория).

## Пример

```markdown
# Компоненты для несущей платы

| № | Название папки | Компонент |
|:-:|:---------------|:----------|
| 1 | [connectors/comexpress](connectors/comexpress) | [3-1827253-6 (разъём COM Express Type 6, Molex)](connectors/comexpress/3-1827253-6.pdf) |
| 2 | [connectors/molex](connectors/molex) | [Разъёмы Molex (каталог)](connectors/molex) |
```
